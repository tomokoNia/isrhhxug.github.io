这个目录放你自己的图片、字体、PDF 等静态素材。

========================================================================
怎么在文章里插入图片（三步）
========================================================================

第 1 步：把图片文件放进这个目录
         src/assets/我的照片.jpg

第 2 步：在文章（src/posts/xxx.md）里写这一行

         ![图片说明](/assets/我的照片.jpg)
          ^^^^^^^^  ^^^^^^^^^^^^^^^^^^^^
          alt 文字    图片的路径

第 3 步：提交
         git add src/
         git commit -m "新增图片"
         git push

就这么简单。GitHub 会自动构建，图片会出现在文章里。


========================================================================
路径怎么写
========================================================================

推荐以 / 开头：

    ![一张照片](/assets/photo.jpg)

这个写法对所有部署方式都正确。如果你将来把网站部署在
https://用户名.github.io/仓库名/ 这样的子路径下，构建脚本会自动
把它改写成 /仓库名/assets/photo.jpg，你不用改文章。

也可以用相对路径（两个 ../ 是因为文章地址形如 /posts/文章名/）：

    ![一张照片](../../assets/photo.jpg)

这种写法只在"部署在域名根目录"时正确，所以更推荐上面那种。


========================================================================
完整的图片语法
========================================================================

    ![说明文字](/assets/pic.jpg)              基本用法
    ![说明文字](/assets/pic.jpg "图片标题")    带标题（鼠标悬停时显示）
    [![说明文字](/assets/pic.jpg)](https://example.com)
                                              图片包链接（点图跳转）
    ![说明](/assets/pic.jpg){width=300}       本项目不支持尺寸语法

想控制大小，可以在图片后面直接写 HTML（本项目允许正文写 HTML）：

    <img src="/assets/pic.jpg" alt="说明" style="width:300px">


========================================================================
注意
========================================================================

1. 图片文件名用中文或英文都可以，都能正常显示。
   但用英文（如 my-photo.jpg）会得到更干净的网址。

2. 图片建议先压缩再放进来。这个项目不做任何图片处理，
   放进来多大，访客就要下载多大。

3. 支持常见格式：.jpg .jpeg .png .gif .webp .svg .avif .ico

4. 图片不会被打包进文章，而是作为独立文件放在 /assets/ 下。
   同一个图片可以被多篇文章引用。

5. 这个 README.txt 本身也会被复制到网站上，但不影响任何东西。
   你可以改成 .md 或者直接删掉。
